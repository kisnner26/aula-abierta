# Aula Abierta Backend

Laravel 11 REST API for the Aula Abierta LMS. The React client communicates only
through `/api/v1`; database and protected storage access remain server-side.

## Requirements

- PHP 8.3
- Composer 2
- PostgreSQL 16

On macOS with Homebrew:

```bash
brew install php@8.3 composer postgresql@16
brew services start postgresql@16
```

## Local setup

```bash
cp .env.example .env
composer install
php artisan key:generate
createdb aula_abierta
php artisan migrate:fresh --seed
php artisan serve --host=127.0.0.1 --port=8000
```

Homebrew creates a PostgreSQL role matching the macOS account. Set
`DB_USERNAME` in `.env` to that account name when the `postgres` role is not
available.

The local API runs at `http://127.0.0.1:8000/api/v1`.

## Development seed users

These users are generated only by the development seeders. Passwords are not documented or hardcoded.
Set `AULA_SEED_*_PASSWORD` values locally if predictable development access is required.

## Storage

Local development uses the private local disk. Production must set
`FILESYSTEM_DISK=r2` and provide the Cloudflare R2 variables from
`.env.example`. Protected material is exposed only through short-lived signed
URLs generated by the API.

## Verification

```bash
php artisan route:list --path=api/v1
php artisan test
composer audit
```

Laravel 11 is currently pinned by the project requirements. Review Composer
security advisories before deployment and plan the supported framework upgrade
when Laravel 11 no longer receives fixes.
