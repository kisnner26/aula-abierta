# Aula Abierta Frontend

React 18 and Vite client for the Aula Abierta open source education platform.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

Set `VITE_API_BASE_URL` to the backend API before signing in.

## Commands

- `npm run dev` starts the development server.
- `npm run typecheck` checks TypeScript without emitting files.
- `npm run build` creates the production bundle.

The frontend includes student, teacher, family, coordinator, and administrator experiences for attendance, assignments, grades, reports, messaging, protected materials, and learning activities.
